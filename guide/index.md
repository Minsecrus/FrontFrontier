# 现代前端开发指南

欢迎来到现代前端开发指南！这是一套面向真实工程实践的前端学习路径，覆盖从 Web 平台底层原理、现代工具链、主流框架渲染模型到前沿工程架构的完整知识体系。

感谢 [Gemini](https://gemini.google.com/) 协助检索资料与打磨细节；感谢 [roadmap.sh](https://www.roadmap.sh/) 提供结构化的学习路线参考。笔者能力有限，如有疏漏或不当之处，欢迎提交 PR 或 Issue 指正。

_全文约 12 万字，预计阅读时间 500~600 分钟。如果你是 AI 全栈开发者，日常深度使用 AI Agent 编写代码，建议优先阅读标有 `（*）` 的章节与小节——这些内容聚焦架构边界、数据契约、质量门禁与验收标准，正是人机协作中最需要工程师亲自把关的部分。_
