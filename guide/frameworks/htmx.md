# IV.5 htmx：超媒体驱动开发

**htmx** 允许用 HTML 实现丰富的交互式 Web 界面，同时最大限度减少 JavaScript 的使用。它通过向服务器发送请求并用返回的 HTML 片段来部分更新页面，利用 HTTP 方法以及 hx-get、hx-target、hx-trigger、hx-swap 等属性完成工作。

**htmx 的哲学**是优先考虑稳定性，谨慎扩展核心功能，专注于通用超媒体控制并支持辅助工具。

htmx 代表了对于 JavaScript 密集型前端格局的一种理念反思。它对超媒体驱动开发的关注，挑战了"复杂交互必须完全存在于客户端"这一假设，为更简单、更快速、JavaScript 开销更少的应用提供了替代方案，对于特定类型的应用可以有效缩短开发周期。
