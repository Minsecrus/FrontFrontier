# 0. 引言

本指南系统梳理了从 Web 平台底层原理到现代前端工程实践的知识体系。前端生态演进迅速，建议按当前所处阶段拆解阅读，边读边在真实项目中验证：

- **初级开发者**：
  请先集中精力攻克第二章“基础 Web 技术”。HTML、CSS、JavaScript 以及浏览器运行机制是所有上层框架的根基。在能够不依赖框架独立完成基础的数据请求、状态更新与页面交互之前，建议将其余章节仅作为拓展查阅资料。

- **中级开发者**：
  可以将本指南作为对照检视自身知识体系的坐标图。重点阅读各章关于渲染模型、状态分层、工具链职责边界与方案取舍的对比分析，理解不同技术方案背后的约束与代价，提升日常技术选型的准确度。

- **高级开发者与架构师**：
  建议重点关注高级工程化工作流、架构边界治理、可观测性体系、安全合规以及新兴技术落地路径，结合团队规模与业务复杂度提炼适合自身组织的技术演进方案。

- **AI 全栈开发者（深度使用 AI Agent 编码）**：
  建议优先阅读标题带有 `（*）` 标记的章节与小节。AI 能够快速生成样板代码与局部实现，但语义化与无障碍、响应式布局、构建与代码规范门禁、状态与接口契约、性能、安全、测试策略及架构边界，仍需开发者提供明确约束并亲自完成验收。

工具和框架的 API 会不断更迭，但对运行环境、数据流动、工程边界与用户体验的底层理解长期有效。
