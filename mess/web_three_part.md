# 网页的三段式

网页常被说成“三段式”，但这句话其实可以从两个角度理解。

第一种是结构上的三段式：头部、主体、底部。

头部解决“我在哪、能去哪”的问题。Logo、导航、搜索、登录入口，通常都放在这里。它像页面的门牌，也像一张简短的地图。

主体解决“我为什么要停留”的问题。文章、产品、工具、表单、列表、案例、交互区域，真正的内容都在这里展开。一个网页有没有价值，往往不是看头部多漂亮，而是看主体有没有把用户真正关心的事情讲清楚、做完整。

底部解决“还有什么可以补充”的问题。版权、联系方式、备案、友情链接、次级导航，通常都放在这里。它不一定承担主要表达，但会给页面一个收束，让信息不至于悬在半空。

这种理解偏向网页的骨架。它适合回答“页面由哪些区域组成”，也适合初学者建立最基本的布局意识。

第二种是叙事上的三段式：吸引、说明、行动。

第一段要吸引用户，让人迅速知道这个页面是什么、和自己有什么关系。尤其是官网、活动页、作品页，首屏往往不只是装饰，而是在争取一次继续阅读的机会。

第二段要展开说明。功能、优势、流程、案例、细节，都可以放在这里。它的任务不是堆信息，而是降低理解成本，让用户从“好像有点意思”走到“我大概明白了”。

第三段要引导行动。注册、购买、下载、咨询、阅读下一篇文章，都是行动。并不是所有网页都追求商业转化，但几乎所有网页都应该让用户知道下一步可以做什么。

这种理解偏向用户的心理路径。它适合回答“页面应该怎样推进用户的理解”，也更接近内容设计和转化设计。

所以，网页的“三段式”并不是一个固定模板，而是一种双重视角。

从结构看，它是 Header / Main / Footer。

从叙事看，它是引起兴趣 / 建立理解 / 促成行动。

前者让网页站得住，后者让网页说得通。一个好页面，通常两者都不会缺席。
