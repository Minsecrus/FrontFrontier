# Front Frontier

> 前端亦可前沿 - Minsecrus 的前端知识分享站

## 简介

Front Frontier 是一个前端知识分享网站，包含以下模块：

- **现代前端开发指南** - 从 Web 基础到前沿技术，系统性的前端开发学习路径
- **小巧思** - 前端开发中的实用技巧与创意实现
- **框架原理教学** - 深入理解主流框架的核心原理
- **进阶专题** - 前端架构设计、微前端、低代码平台等进阶话题

## 技术栈

- [VitePress](https://vitepress.dev/) - 静态站点生成器
- [Vue 3](https://vuejs.org/) - 渐进式 JavaScript 框架

## 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm docs:dev

# 构建生产版本
pnpm docs:build

# 预览生产版本
pnpm docs:preview
```
